# Trey.photography

A luxury cinematic, responsive, single-page photography portfolio. Static HTML/CSS/JS; no build step, paid hosting, or subscription required.

## Publish free with GitHub Pages
1. Create a free account at https://github.com/.
2. Create a **public** repository named `trey-photography`.
3. Upload `index.html` to the repository root and commit.
4. Open **Settings → Pages → Build and deployment**; choose **Deploy from a branch**, branch `main`, folder `/(root)`, then **Save**.
5. After deployment, open `https://YOUR-USERNAME.github.io/trey-photography/`.

## Customize before publishing
- Replace all Unsplash demonstration image URLs in `index.html` with photos you own and have permission to display. Prefer compressed WebP images in an `images/` directory, e.g. `images/portrait.webp`.
- Replace the generic Instagram URL (`https://www.instagram.com/`) with your actual Instagram profile.
- Add your contact email later as a `mailto:` link, or link to a booking form service if its free plan meets your needs.
- Confirm pricing, services, and descriptions.

Note: The sample images are third-party placeholders, not photographs by Trey.photography. Google Fonts and Unsplash URLs require an internet connection. GitHub Pages hosts static sites only; it doesn't process booking form submissions.
